# Windows-проверка для Вадима

Нужно выполнить ту часть подготовки, которая не запустилась на Mac: установить игровой адаптер и проверить обмен Python с Hollow Knight. Основа — этапы 19–21 архива `Лабораторная_Gymnasium_первая_нейросеть.zip`.

## Порядок

1. Проверить запуск Hollow Knight **1.5.78.11833**. Подготовить Python 3.12 x64 и .NET SDK. Мод из комплекта собирается под `net472`; при необходимости установить соответствующий targeting pack.
2. Закрыть игру, сделать копию сохранений из `%USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight` и подготовить тренировочный слот 4 с доступом к Godhome. Вызов `reset()` может загрузить этот слот и перенести героя на арену.
3. Распаковать лабораторную, создать в её папке `.venv` и установить зависимости по `lab.html`. Прочитать README и установочный скрипт из `hollow_knight_adapter`.
4. Установить Python-часть и мод командами ниже. Скрипт при необходимости устанавливает Modding API v77 и меняет файлы игры; сама игра и её DLL в учебный архив не входят.
5. Запустить игру и проверку соединения. После успешного ответа выполнить пример `reset()`/`step()` из этапа 21. Убедиться, что наблюдение соответствует игре, действие выполняется и персонаж не зависает.

Из распакованной папки `laboratory_gym` в PowerShell, заменив путь к игре:

```powershell
$adapterRoot = Join-Path (Get-Location) 'hollow_knight_adapter'
$gameRoot = 'C:\Program Files (x86)\Steam\steamapps\common\Hollow Knight'
.\.venv\Scripts\python.exe -m pip install -e $adapterRoot
powershell -ExecutionPolicy Bypass -File "$adapterRoot\scripts\install_mod.ps1" -GamePath $gameRoot
```

Затем, при запущенной игре:

```powershell
.\.venv\Scripts\python.exe "$adapterRoot\scripts\check_connection.py"
```

Для первой проверки дополнение `[train]` со Stable-Baselines3 не требуется. Если возникла ошибка, сохранить её текст и остановиться на этом шаге; не менять целевую платформу мода наугад.

## Куда записать результат

Создать **`results/windows/README.md`** и кратко указать:

- дату, Windows, версии игры, Python, Modding API и .NET SDK;
- загрузился ли AiTrainHK и ответил ли канал;
- форму наблюдения, пространство действий и результат одного `step()`;
- соответствует ли телеметрия экрану, какие проблемы обнаружены.

При необходимости приложить сюда же один журнал или снимок. Сохранения, игровые DLL и окружение в Git не добавлять. После проверки отметить пункт Вадима в [PLAN.md](../PLAN.md).

Этого достаточно, чтобы перейти к первому игровому эксперименту. Само обучение агента — следующий пункт плана.
