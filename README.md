# HollowKnightAI

Совместный проект Центнера Валерия Викторовича и Зотова Вадима Кирилловича.

Разрабатываем агента для Hollow Knight. Начинаем с подключения игры к Python и экспериментов на одном боссе: получаем состояние, выбираем действия, задаём награду и проверяем, чему научился агент.

## Сейчас

- Разобраны основы нейросетей и интерфейс Gymnasium.
- Собраны [ссылки на существующие решения](docs/references.md).
- Следующий шаг — проверить игровой адаптер на Windows. Эту часть выполняет Вадим; на Mac прилагаемый адаптер не запускался.
